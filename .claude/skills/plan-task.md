# Skill: plan-task

## When to use

Use this skill when:
- the task is new
- the requirements are unclear
- multiple files will be affected
- architecture decisions are required

---

## Instructions

1. Read:
   - SPEC.md
   - CLAUDE.md
   - repo-map.md

2. Understand:
   - business rules
   - impacted modules
   - dependencies

3. Produce a plan with:

- goal
- affected files
- step-by-step implementation
- risks / edge cases

---

## Output format

- clear steps
- no code implementation
- concise and structured

---

## TDD Requirement

Every plan involving business logic MUST include:

- test creation step BEFORE implementation

---

## Important

DO NOT implement anything.
ONLY plan.
